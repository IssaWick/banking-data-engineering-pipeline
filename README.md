# Banking Data Engineering Pipeline

## Overview

This project is an end-to-end data engineering pipeline designed to simulate the processing of banking transaction data.

The project focuses on collecting raw transaction data, validating and transforming the data, storing it in a database/data warehouse, orchestrating data pipelines, performing data quality checks, and preparing the processed data for analytics.

## Project Goals

* Build a complete data engineering pipeline from raw data to analytics
* Practice Python for data ingestion and processing
* Develop strong SQL skills for data transformation and analysis
* Work with PostgreSQL as a data storage and warehouse technology
* Learn data validation and data quality practices
* Implement pipeline orchestration using Apache Airflow
* Learn data transformation using dbt
* Containerize the project using Docker
* Connect processed data to Power BI for analytics
